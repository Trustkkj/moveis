## Tipografia

Nenhuma fonte externa é distribuída ou carregada. O projeto utiliza as fontes de sistema `Georgia`, `Times New Roman`, `Arial`, `Helvetica` e os fallbacks genéricos `serif` e `sans-serif`, conforme disponibilidade e licenciamento do sistema do visitante. Não há arquivos de fonte proprietária no repositório nem dependência do Google Fonts.

## Símbolos e código visual

O monograma geométrico inspirado em N, favicon `simbolo.svg`, ícones de especialidades e elementos gráficos foram desenhados originalmente para este projeto em SVG/CSS. Nenhuma marca preexistente ou ícone de terceiros foi incorporado. Setas e asteriscos são caracteres tipográficos renderizados pelas fontes do sistema.

## Bibliotecas e serviços

O site entregue não possui dependências JavaScript de terceiros, CDN, analytics, pixels ou scripts externos. `IntersectionObserver` e `<dialog>` são APIs nativas do navegador. WhatsApp só é aberto após configuração explícita de número autorizado e ação do visitante; permanece desativado nesta entrega.

Ferramentas temporárias de desenvolvimento, não distribuídas no site: Sharp (Apache-2.0) para conversão das imagens e Playwright (Apache-2.0) para testes de navegador. Seus pacotes não fazem parte do repositório nem são necessários para executar ou publicar o site.
